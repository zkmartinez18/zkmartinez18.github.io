Introduction to Cybersecurity

Cybersecurity is the practice of protecting computers, networks, and digital information from unauthorized access, attacks, and damage.

Three important goals of cybersecurity are confidentiality, integrity, and availability. Together, these from the CIA Triad.

Confidentiality + Integrity + Availability

Network Security

Network security protects devices and information as they communicate across a network. It uses tools and policies to reduce unauthorized access and cyberattacks.

  • Use firewalls to filter network traffic.
  • Keep routers and network devices updated.
  • Separate sensitive devices into secure networks.
Network Security = Protection of Connected Devices

Firewalls

A firewall monitors incoming and outgoing network traffic. It uses security rules to allow or block connections.

Firewalls can be software installed on a computer or hardware devices that protect an entire network.

Allow Trusted Traffic | Block Unauthorized Traffic

Encryption

Encryption converts readable information into ciphertext. Authorized users can decrypt the information using the appropriate key.

Encryption helps protect sensitive data stored on devices and information transmitted across networks.

Plaintext -> Encryption -> Ciphertext

Multi-Factor Authentication

Multi-factor authentication, or MFA, requires users to provide more than one type of verification before accessing an account.

  • Something you know, such as password.
  • Something you have, such as a security key.
  • Something you are, such as a fingerprint.
Password + Security Key = Two Authentication Factors

Password Security

Strong passwords help prevent unauthorized account access. Every important account should have a unique password.

Password managers can generate and securely store strong passwords, reducing the need to memorize them.

Use long, Unique Passwords + MFA
