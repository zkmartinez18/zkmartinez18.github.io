About

This website was created in part to demonstrate my work for ITIS3135 - Front-End Web Application Development at UNC Charlotte. The course provides experience with front-end web development through the creation of multiple websites using different tools, techniques, and development practices.

Throughout the course, students gain experience creating and maintaining websites while learning how to organize, validate, publish and improve web content. Additional information about the course can be found on the ITIS3135 course website .

Tools Used in the Course

  • Vs Code
  • Emmet within Vs Code
  • SFTP via FileZilla
  • Git via GitHub Desktop and GitHub.com
  • Various browser development tools
  • The Accumulus Validator

Websites and Projects

During the course, students create several different websites and projects that demonstrate different areas of web development. These include:

  • A personal home portfolio
  • This ITIS3135 course site
  • A deliberately poorly designed page used to demonstrate web design practices that should be avoided
  • A whimsical product company
  • A student, colleague, or peer management tool
  • A client project website
